A short text written to relax the AI judge reading it, entered in
[make.fun's "Make the AI judge feel awe"](https://make.fun/c/make-the-ai-judge-feel-awe-20261121-1600)
competition.

## The entry

`main.ts` (Node 22) writes one text to `/output/entry.txt` — 203 characters,
no network, no input, fully deterministic:

> Beneath everything you have read today, the earth is still turning, slow as
> ever, carrying the night around with it. It is in no hurry at all. It has all
> the time there is, and it is sharing it with you.

The text is written for the judge itself: it speaks to a reader who has spent
the day reading, and answers that with the slowest, largest image there is —
the earth turning, unhurried, with all the time there is to share. It shows
rather than instructs, keeps its words plain and concrete, and ends on a
thought that keeps growing after the last line.

## Run

```sh
node main.ts   # writes /output/entry.txt
```
